# MCP tool reference

Generated by `scripts/gen_tool_reference.py` from the running server definition (67 tools). Every tool returns a JSON object (structured content); failures are returned as tool errors whose text is `{"error": {"code", "message", "retryable", "details"}}`.

Annotations: **RO** read-only, **ACQ** acquires/changes acquisition state (analysis tools are ACQ because they acquire a new record when called without a `capture_id`), **SET** changes instrument settings (idempotent), **DEL** destructive.

## Instrument and connection

### `scope_connect` (ACQ)

Open the configured backend (USB hardware or the explicitly configured simulator), synchronise the
protocol and read the instrument's identity and settings layout. The backend is fixed by server
configuration; this tool never silently falls back to simulation.

### `scope_disconnect` (ACQ)

Release the USB device so other programs (or the GUI) can use it.

### `scope_status` (RO)

Connection state, backend (hardware/simulator), firmware, acquisition/trigger state, busy operation,
active workflow and scaling-verification status.

### `scope_identify` (RO)

Model, firmware and FPGA version (from /sys.inf), USB endpoints and settings-layout source.

### `scope_get_capabilities` (RO)

Allowed V/div (per probe), timebases, trigger options, capture modes, limits, per-feature verification
status and input safety ratings. Call this before changing settings.

### `scope_get_settings` (RO)

Read the complete settings record back from the instrument and decode channels, trigger, timebase and
acquisition. Each decoded table carries its provenance.

| parameter | type | required | default | constraints | description |
|---|---|---|---|---|---|
| `include_raw` | boolean |  | `False` |  | Also return every raw field of the settings record |

### `scope_get_health` (RO)

Echo round-trip test, protocol error counters, capture-store usage and free disk space.

| parameter | type | required | default | constraints | description |

| `timeout_s` | number |  | `5.0` | > 0, <= 3600 | Seconds to wait for the trigger |

### `scope_capture` (ACQ)

Acquire and download a complete numerical record (raw 8-bit samples + time + volts) for one channel.
Returns compact metadata and a capture_id (no bulk arrays): freshness, scaling status, quality (clipping,
ADC utilisation, stale detection) and warnings. Use scope_get_samples for data.

| parameter | type | required | default | constraints | description |
|---|---|---|---|---|---|
| `channel` | integer | yes |  | >= 1, <= 2 | Input channel: 1 (CH1) or 2 (CH2) |
| `mode` | `single` \| `stop_and_read` \| `running` |  | `single` |  | single: arm Single-Sequence and wait for a confirmed new trigger (default, most trustworthy); stop_and_read: stop and download the frozen record; running: download while running (fastest, freshness not guaranteed) |
| `timeout_s` | number |  | `5.0` | > 0, <= 3600 | Seconds to wait for the trigger |
| `force_on_timeout` | boolean |  | `False` |  | If no trigger occurs, force one (record is then not trigger-aligned; freshness=forced_new) |
| `label` | string (optional) |  | `None` |  | Optional label stored with the capture |
